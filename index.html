🔥 Firebase 설정이 필요합니다

아래 순서대로 설정하면 팀원과 실시간 공유가 가능합니다. (약 10분 소요)

1
Firebase 프로젝트 생성 console.firebase.google.com 접속 → Google 계정 로그인 → "프로젝트 만들기"
2
Firestore 데이터베이스 활성화 왼쪽 메뉴 → Build → Firestore Database → "데이터베이스 만들기" → 테스트 모드 선택
3
웹 앱 등록 후 설정 복사 프로젝트 설정(⚙) → 내 앱 → 웹 아이콘(</>) → 앱 등록 → firebaseConfig 복사
4
이 HTML 파일에 붙여넣기 파일을 메모장/VS Code로 열어 상단 firebaseConfig 부분을 복사한 값으로 교체 후 저장
5
Netlify Drop으로 팀 공유 app.netlify.com/drop 에 파일 드래그 → 생성된 링크를 팀원에게 공유
